LimbusLyric · Lyric Studio 前端优化版

使用方式
1. 将整个压缩包解压到一个新文件夹。
2. 关闭正在运行的旧版本，再运行 START_HERE.cmd。
3. 此包与原包一样是源码版，需要原有 Python 及项目依赖环境；不是独立 EXE 安装包。
   原有构建脚本、图标、依赖清单均保留，可按原项目流程打包。
4. 原项目配置路径保持不变；新版仍使用原软件的已保存配置。

本次修改
深墨绿与暖金配色、唱片纹理状态区、清晰的字号层级、圆角分区导航、
字幕与动效舞台、设置卡片与控件状态、窄窗口装饰收纳和小窗口预览适配。
保留原来的导航、读词、预设、单曲 DIY、搜索、缩放、OBS 和桌面字幕入口。
缩放入口改为使用最终样式，并在字体基准恢复后重新建立 Qt 样式缓存。
没有增加运行依赖、外部字体、在线图片或常驻视觉动画定时器。

验证
实际创建 Windows Qt 窗口，检查五个工作区、全局搜索/清空、字体滑块绑定、
动效重播、100%/125%/150% 缩放和 800×760 小窗口。
原项目 H73、H74、H77、H78、H79、H80 检查通过；H85 为 33/33 通过。
AST 对照确认：原有函数只修改 H74PreviewStage.paintEvent 与 _h12_apply_scale；
其他原有函数体（含播放器、歌词同步与桌面渲染）保持一致。新界面以独立呈现代码接入。
源码锁与 SHA256 清单已针对本修改版重新生成，不代表原作者发布认证。

可重跑界面检查：
