# Runtime Convergence R2.1

This release treats RC11 H95F9 as an interaction/performance reference, not as a code base to copy back wholesale.

Changes are intentionally narrow:
- First safe ordinary lyric may display before same-provider bilingual pairing or precise enhancement finishes.
- KuGou search-only artist enrichment no longer mutates the player-owned transport identity.
- Rapid track-switch bursts receive a short cancellation window only for subsequent jobs; first launch has no debounce tax.
- A KuGou transport generation change invalidates queued/pending mouse seek evidence while preserving learned rail geometry.

Preserved from R2/R1:
- frontend/runtime wrapper chains and effects;
- provider/version safety and provisional precise-lyric rules;
- KuGou background monotonic holdover and visual-rail quarantine;
- QQ advancing UIA duration self-proof and upstream circuit breaker;
- unified lyric/local import/provider/playback/fault core.

The renderer is not structurally rewritten here. Field logs are still required before claiming the remaining multi-row frame-cost issue is solved.
